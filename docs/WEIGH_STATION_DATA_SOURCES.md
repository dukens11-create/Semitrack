# Weigh-station data source register

No state is marked complete until an authoritative enforcement-location dataset has been imported, deduplicated, and validated. The bundled state files currently provide an offline-safe empty fallback instead of fabricated locations. The [FHWA state transportation directory](https://www.fhwa.dot.gov/about/webstate.cfm) is the starting point for locating each official agency; it is not itself a weigh-station dataset.
